# Buniyaad — Frontend prototype

## Run
Extract the ZIP and open `index.html` in a modern browser. VS Code Live Server is also supported. No build step, server, login, API key, or paid service is required.

## Features
- Teacher overview and classroom skill snapshot
- Learner roster, search, filtering, add learner and learner detail
- Reading and numeracy assessment entry
- Transparent rule-based action suggestions
- Mark action plans complete
- Assessment history and follow-up list
- School-level aggregate dashboard
- Browser localStorage persistence and reset-demo control

## Boundaries
All initial learner records are fictional. Data remains in the current browser and is not shared across devices. This prototype does not connect to UDISE+, PARAKH, ASER, DIKSHA, or any government database. It is not a validated assessment instrument; teachers must use professional judgement and curriculum-aligned checks. Do not enter real children's personal or sensitive information.

## Files
- `index.html`: interface structure
- `styles.css`: responsive visual design
- `app.js`: sample data, workflow logic, local storage and interactions
